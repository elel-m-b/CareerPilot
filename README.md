# Resume Analyzer

## Description

Resume Analyzer is a web application that helps users analyze their resumes and receive useful feedback. It extracts information from PDF and DOCX resumes, evaluates different resume sections, and provides recommendations to help users improve their resumes.

## Core Objectives

- Upload resumes in PDF and DOCX formats.
- Extract resume content automatically.
- Analyze resume sections such as skills, experience, education, and projects.
- Provide a resume score and analysis results.
- Generate recommendations for improving the resume.
- Save previous resume analyses.
- Allow users to create accounts and securely manage their resumes.
- Provide a dashboard to view resume statistics and analysis history.

## Target Audience

Resume Analyzer is designed for:

- Students looking for internships or first jobs.
- Job seekers who want to improve their resumes.
- Developers and professionals preparing for job applications.
- Anyone who wants quick feedback on the quality and structure of their resume.
